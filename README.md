# Würfel-Zettel (Mehrspieler)

Gewürfelt wird in echt – die App ist der digitale Spielzettel.

Start:
  npm install
  npm start        (läuft auf http://localhost:3000)

Host: "Runde erstellen" -> Link aus dem Warteraum an Mitspieler schicken -> "Spiel starten".
Jeder trägt in seinen eigenen Zettel ein. Am Ende werden die Punkte verglichen.
